Panduan Penggunaan

Tips untuk hasil terbaik

📌 Format yang Disupport
Hanya file .docx (Word 2007+). Jika filenya .doc, buka di Word dan Save As .docx terlebih dahulu.
🎯 Deteksi Heading Otomatis
Sistem mendeteksi "BAB I", teks HURUF KAPITAL, dan nama seksi umum seperti Pendahuluan, Metodologi, Daftar Pustaka, dll.
📐 Standar Laporan Akademik
Pengaturan default mengikuti standar umum: Times New Roman 12pt, spasi 1.5, margin normal, teks rata kanan-kiri (justify).
🔢 Nomor Halaman
Centang "Tambah Nomor Halaman" untuk menambahkan nomor halaman di tengah bawah secara otomatis.
⚠️ Cadangkan File Asli
Selalu simpan salinan file asli sebelum memformat. File yang sudah dirapihkan tidak bisa dikembalikan ke format semula.
